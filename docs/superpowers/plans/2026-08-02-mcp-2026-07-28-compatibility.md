# MCP 2026-07-28 Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade AlbumentationsX MCP to the MCP Python SDK 2.x and serve modern `2026-07-28` and legacy clients
without changing the public AlbumentationsX MCP contract.

**Architecture:** Keep SDK code at the composition boundary, replace SDK-private profile copying with a local
registrar protocol and filtering proxy, construct the preview UI through the official Apps extension, and verify both
protocol eras through public client/server APIs.

**Tech Stack:** Python 3.10+, MCP Python SDK 2.x, Pydantic v2, AlbumentationsX, pytest, Ruff, ty, uv.
